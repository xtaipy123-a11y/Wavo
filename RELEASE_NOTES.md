# Neu in Wavo 0.1.47

- Songs können über ihr Menü für die Offline-Wiedergabe gespeichert werden. Die gespeicherten Songs stehen unter „Bibliothek → Downloads“ bereit.
- Gespeicherte Songs bleiben erhalten, wenn der normale Audio-Cache geleert wird.
- Playlists und Alben/EPs können wiederholt und direkt im Freunde-Chat geteilt werden.
- Gemeinsame Hörsessions haben eine Warteschlange: Der Host kann Gästen das Hinzufügen, Überspringen und Umsortieren von Songs erlauben.
- Nach einem App-Update zeigt Wavo beim nächsten Start die Änderungen dieser Version an.
- Bereits heruntergeladene App-Updates werden beim Neustart im Hintergrund installiert; Wavo öffnet danach direkt die neue Version.
- Die Darstellung von Freunden, Chat und gemeinsamer Hörsession wurde für kleinere Fenster verbessert.
